急落・下落の8つのサイン

解説動画（11/16回）で挙げられている急落パターンの8条件です。点灯が多いほど急落・下落しやすいとされます。売買の判断はご自身で行ってください。

反発・上昇の条件

ショートカバー・バンドウォーク終了・VIX・「急落は3日待て」・逆ダイバージェンス・PER理論株価の条件です。

注意点

買い・売りの判断を左右する状況（バンドウォーク中、25日線の向き、信用期日など）です。

判定の基準と出典

基準は index.html 冒頭の TH で変更できます。「近似」は、動画の考え方（トレンドラインなど目で引くもの）を数値で判定するために決めた値です。パラボリックは高値・安値データが無いため終値で計算しています。一目均衡表・フィボナッチ・エリオット波動は未対応です。

日経平均・ボリンジャーバンド・パラボリック・移動平均

終値ベース（FRED）。ボリンジャーは20日±2σ。点＝パラボリック（緑＝陽転、赤＝陰転、終値で計算）。凡例を押すと5日線・75日線も表示できます。

MACD（12, 26, 9）

MACD線がシグナル線を上抜け＝ゴールデンクロス、下抜け＝デッドクロス。単独のクロスは騙しが多いので、RSIのライン突破と重なるかを見ます。

RSI（14日）

80以上＝過熱、20以下＝売られ過ぎ。上値・下値のラインの突破／割れに注目。

VIX と パラボリック

点＝パラボリック（赤＝陽転＝VIX上昇トレンド＝株は売られやすい、緑＝陰転）。

VIXのMACD

ゴールデンクロス（赤い棒）＝ヘッジ売り・仕掛け売りで株価急落、デッドクロス（緑の棒）＝底打ち・上昇転換。米国SQ週までに解消しないと要警戒。

日経レバ（1570）の信用倍率

1倍以上＝急落サイン、1倍未満（売り方優勢）＝ショートカバーが起きやすい。JPX「銘柄別信用取引残高」（日次、株数ベース）。

NS倍率（日経平均÷S&P500）

25日平均を下回って低下中＝日本株の優位性低下（急落サインの④）。

空売り比率（東証・日次）

空売り（価格規制あり＋なし）÷売買代金。

ドル円・ナスダック

信用倍率と信用評価損益率

評価損益率は-10%前後で追証売りが一巡しやすく「底」、0%近辺で「天井」の目安とされます。信用倍率は3倍以上で警戒、5倍以上で超危険（解説動画）。

データの出どころと計算方法
  • 信用残：JPX「信用取引現在高」二市場合計（毎週火曜公表）。信用倍率＝買い残÷売り残（金額）。
  • 信用評価損益率：JPXは公表していないため、実績は手入力（docs/data/manual_eval.csv）、推計は「買い残金額（＝約定代金）を日経平均の値動きで時価に引き直す」方法で直近の実績値を起点に計算。誤差の目安は±1〜2ポイント。
  • 日経PER/PBR/EPS：日経平均プロフィルの公表値（stock-marketdata.com経由で取得）。終値はFRED（NIKKEI225）。
  • 投資主体別：JPX「投資部門別売買状況」二市場の金額差引き（千円）を百万円に換算（毎週木曜公表）。
  • 空売り比率：JPX「空売り集計（日次）」（価格規制あり＋なし）÷売買代金。毎営業日公表。
  • テクニカル：日経平均の終値（FRED）から計算。ボリンジャーバンド＝20日移動平均±2σ、MACD＝12日EMA−26日EMA（シグナル9日）、RSI＝14日（ワイルダー方式）。高値・安値が無いため一目均衡表・パラボリック・ストキャスティクスは未対応。
  • VIX・ドル円・ナスダック・S&P500：FRED（VIXCLS・DEXJPUS・NASDAQCOM・SP500）。米国の営業日ベースで1日遅れ。NS倍率＝日経平均÷S&P500。
  • 日経レバ（1570）の信用倍率：JPX「銘柄別信用取引残高」（日次PDF）の買残÷売残（株数）。
  • シグナル画面の判定基準：解説動画9本の内容（Googleドキュメント「SHO手法まとめ」）にもとづく。
  • 画面上部の相場（TradingViewのウィジェット）：日経225＝CFD（OANDA、リアルタイム・24時間）、日経先物・TOPIX先物＝大阪取引所（20分遅れ）、ドル円＝リアルタイム、金・WTI原油＝TradingViewの価格（無料ウィジェットではCOMEX・NYMEXの先物そのものは表示できないため）。TOPIXの指数そのものも無料ウィジェットでは表示できないため先物で代用。
