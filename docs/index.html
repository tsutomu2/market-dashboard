急落・下落の8つのサイン

解説動画（11/16回）で挙げられている急落パターンの8条件です。点灯が多いほど急落・下落しやすいとされます。売買の判断はご自身で行ってください。

反発・上昇の条件

ショートカバー・バンドウォーク終了・VIX・「急落は3日待て」・逆ダイバージェンス・PER理論株価の条件です。

注意点

買い・売りの判断を左右する状況（バンドウォーク中、25日線の向き、信用期日など）です。

判定の基準と出典

基準は index.html 冒頭の TH で変更できます。「近似」は、動画の考え方（トレンドラインなど目で引くもの）を数値で判定するために決めた値です。パラボリックは高値・安値データが無いため終値で計算しています。一目均衡表・フィボナッチ・エリオット波動は未対応です。

SHO手法のしくみ（3つの順番で見る）

  1. まず需給：空売りの残高（信用売残）や信用倍率で、「あとで出てくる買い・売り」がどちらに多いかを見る。空売りが多いほど下げにくく、信用買いが多いほど下げたときの投げ売りが大きい。
  2. 次に恐怖指数とチャート：VIX（恐怖指数）が上向きか下向きか、ボリンジャーバンド・移動平均・RSIで勢いが続くか終わるかを見て、売買のタイミングを決める。
  3. 最後に値段のものさし：PER・PBRで「どこまで下がれば割安か（PER14倍・13倍）」「どこが上値の壁か（PER16倍・PBR2倍）」を決め、損切りと利確の目安にする。

YouTube「Sho's投資情報局」の手法まとめ（9本）と最新100本の要約にもとづき、数値で判定できるものを自動で判定しています。各項目の★は重要度です（過去3年のデータでの効き目、データが足りないものは動画で触れた本数から）。

ことばの説明
  • 信用取引：お金や株を証券会社から借りて売買すること。借りたものは6ヶ月以内に返す（信用期日）。
  • 空売り（信用売り）：借りた株を先に売り、あとで買い戻して返す取引。下がると利益になる。
  • 信用売残・買残：まだ返済されていない空売り・信用買いの残高。売残はいずれ「買い」、買残はいずれ「売り」になる。
  • ショートカバー（踏み上げ）：空売りした人が損を抑えるために一斉に買い戻し、株価が急に上がること。
  • 追証（おいしょう）：信用買いの損が膨らみ、追加の保証金を求められること。払えないと強制的に売られ、下げが加速する。
  • VIX（恐怖指数）：米国株の先行きの不安の大きさ。20以下は落ち着き、30以上は強い不安。
  • ボリンジャーバンド：株価が収まりやすい幅を示す帯。外側に貼り付いて動くのが「バンドウォーク」。
  • MACD：短期と長期の平均の差で勢いを見る指標。上に抜ける（ゴールデンクロス）と上向き、下に抜ける（デッドクロス）と下向き。
  • RSI：買われすぎ・売られすぎの目安（0〜100）。70〜80以上で買われすぎ、20〜30以下で売られすぎ。
  • PER・PBR：株価が1株利益の何倍か（PER）、1株純資産の何倍か（PBR）。低いほど割安。
  • SQ：先物・オプションの清算日。米国は毎月第3金曜。前後に値動きが荒くなりやすい。

この画面は投資手法の考え方をデータに当てはめた参考情報で、売買を勧めるものではありません。判断はご自身で行ってください。

日経平均と各データの相関

相関係数（r）：+1に近いほど同じ向き、-1に近いほど逆向きに動く。水準どうしの相関は、どちらも上昇傾向だと高く出やすいので、「値動き」の相関もあわせて見ます。米国のデータは前夜の値を東京の当日に対応させています。

信用倍率と信用評価損益率

評価損益率は-10%前後で追証売りが一巡しやすく「底」、0%近辺で「天井」の目安とされます。信用倍率は3倍以上で警戒、5倍以上で超危険（解説動画）。

データの出どころと計算方法
  • 信用残：JPX「信用取引現在高」二市場合計（毎週火曜公表）。信用倍率＝買い残÷売り残（金額）。
  • 信用評価損益率：JPXは公表していないため、実績は手入力（docs/data/manual_eval.csv）、推計は「買い残金額（＝約定代金）を日経平均の値動きで時価に引き直す」方法で直近の実績値を起点に計算。誤差の目安は±1〜2ポイント。
  • 日経PER/PBR/EPS：日経平均プロフィルの公表値（stock-marketdata.com経由で取得）。終値はFRED（NIKKEI225）。
  • 投資主体別：JPX「投資部門別売買状況」二市場の金額差引き（千円）を百万円に換算（毎週木曜公表）。
  • 空売り比率：JPX「空売り集計（日次）」（価格規制あり＋なし）÷売買代金。毎営業日公表。
  • テクニカル：日経平均の終値（FRED）から計算。ボリンジャーバンド＝20日移動平均±2σ、MACD＝12日EMA−26日EMA（シグナル9日）、RSI＝14日（ワイルダー方式）。高値・安値が無いため一目均衡表・パラボリック・ストキャスティクスは未対応。
  • VIX・ドル円・ナスダック・S&P500：FRED（VIXCLS・DEXJPUS・NASDAQCOM・SP500）。米国の営業日ベースで1日遅れ。NS倍率＝日経平均÷S&P500。
  • 日経レバ（1570）の信用倍率：JPX「銘柄別信用取引残高」（日次PDF）の買残÷売残（株数）。
  • シグナル画面の判定基準：解説動画9本の内容（Googleドキュメント「SHO手法まとめ」）にもとづく。
